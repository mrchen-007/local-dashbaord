## 详细操作步骤

### 步骤 1：启动后台服务

打开 PowerShell，执行：

```powershell
cd D:\001\2026-06-25\local-dashbaord-master\local-dashbaord-master
powershell -ExecutionPolicy Bypass -File start_services.ps1
```

**服务清单：**

| 服务 | 端口 | 用途 |
|------|------|------|
| SiameseUIE | 8000 | 中文信息抽取 AI 模型 |
| Kreuzberg | 内置 | 文档解析（PDF/Word/Excel/OCR） |

**验证服务启动：**
```powershell
curl http://127.0.0.1:8000/health
```

预期返回包含：`{"status":"ok","model_loaded":true,"model_name":"..."}`。只有 `model_loaded` 为 `true` 才表示可执行字段抽取。

---

### 步骤 2：启动桌面应用

新开一个 PowerShell 窗口：

```powershell
cd D:\001\2026-06-25\local-dashbaord-master\local-dashbaord-master
npm run tauri dev
```

等待桌面窗口出现，标题栏显示 "文件去重工具 V1.1"。

---

### 步骤 3：选择项目文件夹

1. 点击左侧导航栏 **"数据提取"**
2. 点击 **"选择目录"** 按钮
3. 在弹出的文件选择器中，导航到项目文件夹：

```
D:\02.chenwenke2024\09.联营项目\08河北省沙河市第二中学东校区建设工程项目
```

4. 点击 **"选择文件夹"**

---

### 步骤 4：加载文件清单

1. 点击 **"加载清单"** 按钮
2. 系统自动扫描文件夹，生成 `file_manifest.json`
3. 页面显示文件列表（最多 50 个预览）
4. 统计卡片显示：总文件数、待处理数

**预期结果：**
- 发现 XX 个文件
- 文件列表包含：合同 PDF、成本 Excel、结算文件等

---

### 步骤 5：开始处理

1. 点击 **"开始处理全部文件"** 按钮
2. 系统自动执行三阶段处理：

**阶段 1：解析文件（Kreuzberg）**
```
进度条: 解析文件 1/XX
├── PDF → 提取文本内容
├── Word → 提取文本内容
├── Excel → 提取表格数据
└── 图片 → OCR 文字识别
```

**阶段 2：抽取字段（SiameseUIE）**
```
进度条: 抽取字段 1/XX
├── 合同编号
├── 合同金额
├── 甲方/乙方
├── 人工/材料/设备/分包成本
└── 结算金额/日期
```

**阶段 3：保存数据**
```
进度条: 保存数据 1/XX
├── → files 表
├── → parsed_contents 表
├── → extracted_fields 表
└── → ETL 聚合 → projects 表
```

3. 处理完成后查看成功、失败和跳过数量。部分失败会明确提示，不能视为全部完成。
4. 在“字段人工复核”中确认或修改关键字段；原始抽取值、来源片段和确认记录都会保留。

---

## 常见问题

**Q: 看板显示的是模拟数据还是真实数据？**
A: 生产流程不会展示模拟项目。空数据表示尚未完成字段确认或项目聚合，请先查看“数据提取”和“运行诊断”。

**Q: 如何确认数据已写入数据库？**
A: 在数据提取页查看统计卡片：总文件数、已解析、已完成 应 > 0。

**Q: 处理失败怎么办？**
A: 检查：
1. Python UIE 服务是否启动（端口 8000）
2. 文件是否为支持的格式（PDF/Word/Excel/图片）
3. 查看控制台错误信息

**Q: 如何重新处理？**
A: 再次点击 "开始处理全部文件"，系统会自动跳过已处理的文件（基于缓存）。

## 快速启动脚本

创建 `quick_start.ps1`：

```powershell
# 一键启动所有服务
Write-Host "启动工程项目智能数据中枢..." -ForegroundColor Cyan

# 启动 UIE 服务
Write-Host "启动 AI 服务..." -ForegroundColor Yellow
Start-Process powershell -ArgumentList "-Command", "cd python; python start_uie_service.py" -WindowStyle Minimized

# 等待服务就绪
Start-Sleep -Seconds 5

# 启动 Tauri 应用
Write-Host "启动桌面应用..." -ForegroundColor Yellow
npm run tauri dev
```

使用方式：
```powershell
powershell -ExecutionPolicy Bypass -File quick_start.ps1
```
