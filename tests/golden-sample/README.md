# 黄金样本验收集

此目录用于存放不含敏感信息的端到端验收数据。提交真实样本前必须完成脱敏，并同步更新 `expected.json`。

## 目录约定

```text
tests/golden-sample/
  expected.json             # 预期文件数、重复组、项目数和字段真值
  <项目目录>/               # 脱敏后的合同、成本、结算等文件
```

## 执行步骤

1. 用桌面应用扫描该项目目录并完成提取、字段复核和 ETL。
2. 将导出的清单、数据库统计和报告与 `expected.json` 对照。
3. 记录处理成功/失败/跳过数，以及任一字段差异。
4. 发布前必须对同一黄金样本运行一次完整流程。

当前仓库只提供验收结构，不伪造真实工程文件或 AI 抽取结果。
